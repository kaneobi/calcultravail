# Suivi Chantier

Application web personnelle pour suivre les journées de travail, les tâches réalisées, les quantités, les tarifs et les totaux.

## Fonctionnalités

- Suivi des journées
- Plusieurs tâches par journée
- Catalogue de tarifs
- Gestion des chantiers
- Calcul automatique des totaux
- Historique des journées

Application créée pour une utilisation sur PC et iPhone.
